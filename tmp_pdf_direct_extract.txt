Profit & Risk Module
What it does, what data drives it, and exactly what the team needs to build.
What this module is for
The Profit & Risk page answers one question for a Riverland grower: is my crop making money this season,
and what should I be growing instead? It takes real farmgate prices and water costs and turns them into a live
net margin calculation. Right now the page shows only placeholder numbers — 12.4% ROI, "Low" risk, $0 potential
loss. All of that is fake and needs to be replaced with live data from the CSV files.

How to build it — four steps
Each step is self-contained. The team can split these across members and work in parallel on Steps 1 and 3.
 1
Load the XLSX and calculate net margins — Python (Jupyter or script)
 Open the XLSX file in pandas using pd.read_excel().
 For each of the 16 crop rows, calculate Net Margin at 3 water prices: $80, $153, and $420/ML.
 Formula per row: margin = (farmgate_price_mid x yield_t_ha_typical) - (cost_mid x yield) - (water_avg_ml x
water_price).
 This gives 48 numbers (16 crops x 3 scenarios). Save as JSON — this feeds the API in Step 2.
 Test it first in a Jupyter notebook before wrapping in a function.
Code:
import pandas as pd df = pd.read_excel('SA_Commodity_Farmgate_Prices_Water_Requirements.xlsx')
water_scenarios = {'low': 80, 'current': 153, 'high': 420} results = [] for _, row in
df.iterrows(): price = float(row['farmgate_price_mid']) yield_ = float(row['yield_t_ha_typical'])
water = (float(row['water_req_ml_ha_min']) + float(row['water_req_ml_ha_max'])) / 2 try: cost_s =
str(row['cost_of_production_per_unit']).replace('–','-') parts = cost_s.split('-') cost =
(float(parts[0]) + float(parts[-1])) / 2 if len(parts)>1 else float(parts[0]) except: cost = 0
rev_ha = price * yield_ cost_ha = cost * yield_ for scenario, wp in water_scenarios.items():
margin = rev_ha - cost_ha - (water * wp) results.append({'crop': row['variety_type'], 'scenario':
scenario, 'margin': round(margin)}) import json print(json.dumps(results[:3], indent=2)) # check

 2
Build the FastAPI endpoint — returns the margin JSON to Angular
 Create profit_risk_router.py in your FastAPI project.
 Add a GET endpoint at /blocks/{block_id}/profit-risk with an optional water_price query param.
 The endpoint calculates margins (from Step 1 logic) and also returns risk_level (High/Low based on current crop
vs break-even) and best_crop (highest margin crop at current water price).
 No database needed yet — run the calculation in-memory on each request from the XLSX loaded at startup.
Code:
from fastapi import APIRouter router = APIRouter() @router.get('/blocks/{block_id}/profit-risk')
def get_profit_risk(block_id: str, water_price: float = 153.0): margins =
calculate_margins(water_price) # function from Step 1 current_crop_margin =
get_crop_margin(block_id, margins) # e.g. Shiraz risk = 'High' if current_crop_margin < 0 else
'Low' best = max(margins, key=lambda x: x['margin'])['crop'] return { 'margins': margins,
'risk_level': risk, 'best_crop': best, 'net_margin': current_crop_margin }

best_crop goes in the stats strip.
